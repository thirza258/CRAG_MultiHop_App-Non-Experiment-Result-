# CRAG Multi-Hop QA Skill

Use the Corrective RAG pipeline to retrieve documents across multiple hops, validate retrieved passages against web sources, and synthesize verified answers.

## Capabilities

- Multi-hop document retrieval across complex information graphs
- Corrective retrieval with automatic confidence scoring and fallback search
- Real-time reasoning graph visualization and retrieval telemetry
- Factual correctness evaluation and reference citation generation
